# Oakle — мобильное приложение

Клиентское Flutter-приложение для пациентов и психологов. Основной API-сервер: `https://api.oakle.app/api/v1/`.

## Запуск в Android Studio

1. Установите Flutter SDK версии 3.35.2 или новее и плагины Flutter и Dart для Android Studio.
2. Откройте папку проекта.
3. Выполните `flutter pub get` в терминале Android Studio.
4. Подключите Android-эмулятор или телефон с включённой USB-отладкой.
5. Нажмите **Run** или выполните `flutter run`.

Адрес API задаётся в `.env.example`. Сейчас там указан рабочий адрес сервера Oakle. Секреты и персональные данные в этот файл добавлять не нужно.

## Проверка и сборка

- `flutter analyze` — статическая проверка Dart-кода.
- `flutter test` — запускает автоматические проверки слотов, цены в USD, даты рождения и обновления имени на главном экране.
- `flutter build apk --debug` — APK для установки и ручной проверки.
- `flutter build appbundle --release` — Android App Bundle для подготовки к публикации.

Debug APK создаётся в `build/app/outputs/flutter-apk/app-debug.apk`, App Bundle — в `build/app/outputs/bundle/release/app-release.aab`.

## Перед публикацией

- До первой публикации выберите постоянный уникальный Android ID пакета и добавьте `oakleApplicationId=ваш.уникальный.id` в `android/gradle.properties`.
- Создайте личный upload-ключ в Android Studio и настройте `android/key.properties` по образцу `android/key.properties.example`. Ключ и пароли не добавляйте в Git и сохраните резервную копию. Релизная сборка теперь остановится, если ID или подпись не настроены.
- API уже поддерживает загрузку фото через `/psychologists/me/photo`, но экран профиля пока не отправляет фото на сервер.
- Billing API сейчас задаёт USD-ставку за час (`hourly_net_minor`); продукту нужна цена за один сеанс. До подключения оплаты согласуйте новые поля цены и ответы `quote`/`checkout` с сервером.
- Подписки ИИ требуют отдельного подключения Google Play Billing и Apple In-App Purchase. В текущей OpenAPI-схеме есть тестовая подписка, но нет описанного каталога уровней, лимитов ИИ или запроса проверки покупки.
- Проверьте сценарии с тестовыми аккаунтами пациента и психолога, включая запись на сеанс, завершение сеанса, оценку и видеозвонок.
- Сброс пароля должен открывать форму `ResetPasswordScreen` внутри Oakle, а не веб-форму. Для клика из письма используйте HTTPS App Link вида `https://api.oakle.app/reset-password?token=...`: Android App Links и iOS Universal Links должны быть связаны с приложением, а Flutter должен передать токен на экран сброса. Серверу нужно разместить файлы подтверждения домена (`assetlinks.json` для Android и `apple-app-site-association` для iOS); домен, package ID, SHA-256 подписи, Bundle ID и Apple Team ID должны совпадать. Сейчас ссылка `oakle://...` зарегистрирована, но HTTPS-привязка домена ещё не завершена. Веб-форма сброса не требуется; для перехода по ссылке Oakle должна быть установлена.

Дневник и аналитика хранят данные на устройстве и не требуют доступности API. Доступ к функциям психолога зависит от роли аккаунта на сервере.


После переноса на Windows перезапустите Android Studio, чтобы она прочитала пользовательскую переменную PUB_CACHE=G:\FlutterPubCache; это держит кэш пакетов рядом с проектом и предотвращает сбой Kotlin-кэша при сборке между дисками.
